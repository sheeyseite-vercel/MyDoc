# MyDoc — خزنة الوثائق الذكية

## حالة المشروع
تم التحقق فعلياً من: التجميع (`next build`) وفحص الأنواع (`tsc`) واختبارات موجّه AI (6 اختبارات ناجحة).
لم يُختبر مع Supabase حقيقي ولا مع مفاتيح مزودي AI، فاختبر تدفق التسجيل والرفع والبحث والمساعد عندك أولاً.

**منجز:** تسجيل الدخول/الإنشاء، رفع متعدد مع تحقق، المجلدات، بحث مصرّح به، تفاصيل الوثيقة (فتح، تنزيل، إعادة تسمية، مفضلة، أرشفة، ملاحظات)، المحذوفات والاستعادة والحذف النهائي بتأكيدين، استخراج النص والبيانات بالرؤية مع شاشة اعتماد، التذكيرات (90/30/7/1) ومركز تنبيهات شهري، المساعد مع بطاقات «فتح الوثيقة»، التبديل التلقائي بين المزودين، الإعدادات (موافقة AI، حذف المحادثات، تصدير البيانات، الوضع الفاتح/الداكن)، PWA (manifest وservice worker وصفحة offline).

**غير منجز:** Web Push، مزامنة التعديلات دون اتصال (IndexedDB)، تعدد اللغات (الواجهة بالعربية فقط)، مشاركة الوثائق بروابط، الخطط والاشتراكات، قص الصور وتدويرها، سجل النشاط كشاشة (يُسجَّل في القاعدة فقط)، Google OAuth (يُفعَّل من لوحة Supabase دون تغيير الكود)، اختبارات RLS الآلية (يوجد سكربت يدوي في `supabase/tests`)، وجدول حصص مفصّل بالمزود.
حدود المزودين المؤقتة تُحفظ في ذاكرة الخادم وتُصفَّر عند إعادة تشغيله.

## التشغيل المحلي
1. أنشئ مشروعاً في Supabase ونفّذ بالترتيب من SQL Editor: `supabase/migrations/001_init.sql` ثم `002_storage_limits.sql` ثم `003_bills.sql` (قسم الفواتير) (ينشئ bucket خاصاً باسم documents ويقيّد الأنواع والحجم).
2. انسخ `.env.example` إلى `.env.local` واملأ مفاتيح Supabase ومفتاحاً واحداً على الأقل من مزودي AI. لا ترفع هذا الملف إلى Git.
3. `npm install` ثم `npm run dev`، وافتح http://localhost:3000
4. الاختبارات: `npm test`

## الذكاء الاصطناعي
المفاتيح على الخادم فقط. الاستخراج من الصور وPDF يتطلب مزود رؤية (Gemini، أو نموذج رؤية عبر `OPENROUTER_VISION_MODEL`). أسماء النماذج الافتراضية في `lib/ai/providers.ts` قابلة للتغيير من متغيرات البيئة؛ تحقق منها في لوحة كل مزود. التبديل يحدث عند 429 أو quota فقط، وخطأ المفتاح يظهر كخطأ إعداد.

## Google OAuth (اختياري)
Supabase → Authentication → Providers → Google، ثم أضف رابط الرجوع. زر Google غير موجود في الواجهة بعد.

## النشر على Vercel
استورد المستودع، أضف نفس متغيرات `.env.local`، ثم انشر. في Supabase → Authentication → URL Configuration أضف رابط الموقع.

## اختبار PWA
افتح الموقع المنشور (HTTPS) في Chrome على Android → قائمة المتصفح → «تثبيت التطبيق». لاختبار offline: أوقف الشبكة وأعد فتح التطبيق فتظهر صفحة الانقطاع.

## الأمان
RLS على كل الجداول، bucket خاص، روابط موقّعة 60 ثانية، التحقق من الملكية عبر RLS في كل استعلام، والمساعد لا يعيد معرفات من عنده: البطاقات تأتي من استعلام القاعدة. للتحقق اليدوي من العزل استخدم `supabase/tests/rls_check.sql`.
